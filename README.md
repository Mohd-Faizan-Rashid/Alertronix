# Alertronix
an intelligent, ultra-low-cost ($₹1,000–₹1,500) anti-theft luggage tracking tag that overcomes the recurring cost and false-alarm limitations of existing commercial trackers. By deploying an INT8-quantized 1D-CNN model on the Seeed Studio XIAO ESP32-C3 alongside OpenHaystack BLE beaconing and a real-time Telegram control interface.
